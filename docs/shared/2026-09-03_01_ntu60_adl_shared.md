# E01 — NTU60 ADL baseline 재현과 exact 보존

- 문서 ID: `DOC-20260903-exp01-ntu60-adl-R10`
- 기준일: 2026-09-04
- 연구 상태: 역사적 `completed`, 현재 성능 재현 `completed`

## 연구 질문

FoundSkelModel DSTE의 NTU60 Cross-Subject 성능을 재현하고, 낙상 전문 분기 학습 중 기존 60-class
ADL 출력을 완전히 보존할 수 있는가?

## 방법

- NTU RGB+D 60 3D Cross-Subject, 25 joints, 최대 2명, 64-frame 입력
- DSTE와 60-class ADL head는 낙상 학습에서 고정
- 학습 전후 전체 validation logits, sample order와 parameter 불변성을 비교

## 기존 기록 기준 결과

| 항목 | 결과 |
| --- | ---: |
| XSub Top-1 | 85.285% |
| Top-5 | 97.234% |
| 낙상 학습 전후 ADL logit 최대 차이 | 0.0 |
| 비교 validation samples | 16,487 |

전체 logits와 encoder/head parameter가 동일해 ADL 보존을 확인했다. NTU A043 낙상 sanity에서도 기존
ADL logit F1 98.188%, 별도 binary head F1 96.416%로 낙상 정보가 이미 표현에 존재함을 확인했다.

## 해석과 한계

- 85.285%는 native Kinect skeleton 결과이며 RGB-derived ADL 성능이 아니다.
- NTU60만으로 intentional lying이나 실사용 오경보를 검증할 수 없다.
- 역사적 weight가 없으므로 동일 구조의 재학습은 가능하지만 checkpoint의 bit-exact 복원은 불가능하다.

## 현재 재현 결과

공식 DSTE 백본을 고정하고 현재 확보된 56,578개 가공 표본으로 60-class linear head 전체 학습을
완료했다. 백본 불변성 검사는 통과했으나 best validation 결과는 Top-1 79.899%, Top-5 94.899%로,
역사적 기준보다 각각 5.386%p와 2.335%p 낮았다. 따라서 이 실행은 역사적 baseline의 재현으로
채택하지 않는다.

가공 표본의 좌표계를 원본 skeleton과 대조한 결과, 현재 입력에는 프레임별 자세 정규화가 적용되어
공식 UmURL 전처리의 좌표계와 일치하지 않는 것으로 확인됐다. 현재 결과는 전처리 불일치 대조군으로
보존하며, 원본 NTU60 skeleton에서 공식 전처리를 다시 생성하기 전까지 낙상 분기 학습으로 진행하지
않는다.

공식 NTU60 skeleton 원본 56,880개를 확보하고 압축 무결성, S001–S017 setup 범위, A001–A060 행동
범위와 파일명 규칙을 검증했다. 공식 missing-sample 목록 확보와 전처리 계약 대조 후 입력을 다시
생성할 예정이다.

공식 missing-sample 목록 302개도 확보했으며 형식·중복·원본 archive 포함 여부 검사를 통과했다.
다음 단계는 원본을 분리된 디렉터리에 추출하고 유효 표본 56,578개 계약을 확인하는 것이다.

원본 추출 후 전체 56,880개와 제외 후 56,578개 계약을 확인했다. 전처리 실행 전 코드 감사에서 기존
`official_umurl` 경로가 실제로는 다른 데이터셋용 축 정렬 기본값을 호출하는 불일치를 발견했다.
이 상태에서는 전처리를 실행하지 않으며, 이전 실험과 동일한 UmURL 중심·어깨축 정렬을 명시적으로
복원하고 단위 검증한 뒤에만 입력을 생성한다.

이 호출 불일치는 NTU 전용 normalization으로 수정했고 중심·어깨축 regression test를 통과했다.
공식 UmURL XSub 전처리도 완료되어 train 40,091개와 validation 16,487개, 총 56,578개의 joint 입력과
split별 label·frame count 및 완료 manifest를 확보했다. 모든 배열은 유한값이며 두 split은 중복 없이
60개 행동 class를 모두 포함한다. 대표 표본과 축 회전의 수치적 경계 표본까지 공식 구현과 출력이
정확히 일치했다.

새 공식 입력을 기존 입력과 구분해 선택하는 downstream profile도 구현했다. 제한 실행에서 전체
train/validation 표본을 올바르게 인식했고 60-class linear head만 학습 가능했으며, 종료 후 DSTE
백본이 공식 checkpoint와 정확히 동일함을 확인했다. 제한 표본 정확도는 성능 결과로 사용하지 않는다.

동일한 frozen DSTE linear-evaluation 계약의 160 epoch 전체 실행도 완료했다. 기존 기록의 best epoch
150에서 Top-1 85.285%, Top-5 97.234%를 동일하게 재현했다. 전체 구간에서 새로 선택된 best는 epoch
155의 Top-1 85.298%, Top-5 97.234%였으며, DSTE encoder 불변성 검사도 통과했다. GPU 구성과 수치
환경 차이가 있으므로 bit-exact weight 복원이 아니라 동일 실험 계약의 성능 재현으로 판정한다.

SAFER의 과거 F0A 조건과 맞추기 위해 동일 설정을 정확히 epoch 150에서 종료한 ADL head도 별도로
재생성했다. Top-1 85.285%, Top-5 97.234%와 encoder 불변성을 다시 확인했다. 과거 weight 자체는
남아 있지 않으므로 이 산출물도 성능·설정 재현으로 사용하며 bit-exact 복원으로 보지 않는다.

FU linear control과 SAFER raw audit까지 완료했으므로 다음 단계는 재현한 encoder와 ADL head를 계속
고정한 채 SAFER legacy 입력과 F0A/F0B/F1, corrected V2/V3를 순서대로 복구하는 것이다. 이후
J0/J1에서도 ADL 보존은 전체 validation logits의 동일성으로 검사한다.
