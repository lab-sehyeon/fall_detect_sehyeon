# E10 — Le2i 저해상도 engineering external

## 평가 역할과 데이터

Le2i는 저해상도 실내 영상에서 RGB→pose→skeleton→event 전체 경로의 실행 가능성을 확인하는
engineering external이다. 평가 가능한 127개 영상은 fall 96개와 negative 31개로 구성됐다.

## 기존 기록 기준 결과

- 전체 영상의 production decoder 완독을 확인했다.
- quality pass는 109/127이었다.
- locked primary G2: Precision 84.946%, Recall 82.292%, F1 83.598%
- post-hoc G0: Precision 85.106%, Recall 83.333%, F1 84.211%

G0가 사후 비교에서 0.613%p 높았지만 결과 확인 뒤 수행한 분석이므로 locked G2 primary를 대체하지
않는다.

## 해석과 한계

저해상도 경로의 실행 가능성은 확인했으나 작은 표본과 negative 분포 편향이 있다. quality-pass
subset만 단독 보고하지 않고 전체 결과와 입력 적격성을 함께 제시한다. 최종 외부 확증은 별도 봉인
데이터에서 수행한다.
