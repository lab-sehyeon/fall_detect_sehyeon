# V3 유효 2D 근거 기반 재검산

- 기준일: 2026-09-23
- 상태: `completed` — R3 전체 실행 및 독립 검산 완료

## 최신 완료 확인 — 9월23일

전체497개/8,091,357프레임의 전처리와 후속 기준 모델·공동학습·FU 고정 비교가 완료됐다. 전체 geometry 경계 이상 비율은97.155% 감소했고 고정 기준을 통과했다. 아래pilot 진행 문장은 당시 이력이다. [후속 데이터 준비와 확인 결과](2026-09-23_rgb_data_acquisition_shared.md).

이전 V3 실험에서는 원본 2D 좌표가 모두 0인 프레임 때문에 추가 퇴화 입력 검사를 통과하지 못했다.
그 결과는 보존하며, 이번 R3는 **이전 결과를 확인한 뒤 평가 정의를 보완한 별도 post-hoc 실험**이다.
소실된 원본 실험과 수치적으로 동일한 복원이 아니다.

원본 프레임·학습 window는 그대로 유지한다. 원본 2D 관절 bbox의 대각선이 양수인 프레임에서만
재투영 NME를 계산한다. seam은 중심 속도와 앞뒤 최대5개 참조 속도를 구성하는 모든 원본 프레임이
유효할 때만 평가한다. 같은 source-only 규칙을 V2와 모든 후보에 적용하며 유효·제외 수를 보고한다.
라벨·모델 성능으로 프레임을 선택하지 않는다. 3D bone CV·speed·root·출력 퇴화 검사는 전체 시간축에 유지한다.

pilot8개와 모델·추론·후보 순서, seam 감소75% 이상 및 NME/boneCV/speed 비율 제한은 유지한다.
검증을 통과한 경우에만 전체 전처리와 matched controls·J0/J1 비교를 진행한다.
2D 근거가 없는 프레임의 seam 정확도와 의미적 3D 정확도를 이 평가로 주장할 수 없다.

## Pilot 결과와 후속

8 sequences의25,928프레임 중25,308개(97.609%)에 유효한 2D 근거가 있었다.
V2는 지원 가능한 경계107개 중86개, stride121+triangular는391개 중13개가 artifact였다.
경계 이상 비율은95.863% 감소했고, NME p95·bone CV p95·speed p99 비율은
각각1.004289/1.006171/0.868549로 고정 기준을 통과했다. V2 재추론 값은 저장 값과 정확히 일치했다.
전체 경계 중 지원 부족으로 제외된 수는 V2 4개, 후보13개이며 원본 입력에서 삭제한 것은 아니다.

정해진 후보 순서에 따라 stride121+triangular를 선택했고 전체497개 전처리를 진행 중이다.
전체 geometry 검산·분류 학습은 아직 완료되지 않았으며, 낙상 성능 개선을 뜻하지 않는다.

공동학습 완료 후 기존 FU 4종 분류기와 V3 J0/J1의 동일 nested OOF를 비교한다.
기존 분류기를 재학습·재선택하지 않고 고정 모델의 예측 및 평가를 다시 검산한다.
