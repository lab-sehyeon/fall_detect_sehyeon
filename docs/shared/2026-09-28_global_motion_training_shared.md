## 결과 요약

원자료를 보존한 별도 전처리와 문서 기반 재구현으로 G0/G1/G2를 각각 50epoch 학습했다.
Validation으로 모델을 선택한 뒤 test/OOD 고정 평가와 독립 검산을 완료했다.
아래는 이번 재구현의 확정 결과이며, 소실 이전 실험과 수치적 동일성을 주장하지 않는다.

| --- | ---: | ---: | ---: | ---: | ---: | ---: |

G2의 사전 채택 조건은 G0 대비 validation Macro-F1 0.5%p 이상 향상,
fall recall과 lie-down F1 저하 각각 1%p 이하다. 실제 Macro-F1 향상은 **0.089%p**에 그쳐
G2를 채택하지 않았다. 두 안전 조건은 통과했지만 전체 채택 조건은 충족하지 못했다.
OOD fall recall도 G0 75.000%에서 G2 70.576%로 감소했다. 소폭의 OOD fall F1 증가를
모든 지표·도메인에서의 우위로 해석하지 않는다. 추가 학습이나 결과 기반 재선택은 하지 않았다.

## 수정한 데이터

SAFER의 해상도 차이는 공식 추출 과정의 1920×1080 리사이즈와 대응한다. 기존 pose 좌표는
변경하지 않고 RGB 입력의 동일 리사이즈를 명시했다. 확보한 30개 영상의 프레임 수와 좌표 정합을
확인했다. 현재 공식 구현이 당시 배포 자료의 완전한 생성 이력까지 입증하는 것은 아니다.

OOPS 818개 전체에 동일한 실제 비디오 시간 구간 제한을 적용했다. 643개 라벨의 끝부분
총 9.415초를 제한했으며 영상이나 라벨 행을 완전히 제외한 사례는 없다. 낙상 914행과
정규화 라벨 4,021행을 유지했다. 25fps 입력 시각 238,602개는 모두 해당 시각까지 실제로
관측된 프레임에 대응한다. 원영상·원라벨은 보존했으며, 문제 확인 후 적용한 별도 사후 수정이다.
OOPS는 이번 모델 학습·선택에 사용하지 않았고 외부 모델 평가도 아직 수행하지 않았다.

## 학습 방법과 검증

고정 J1의 2048차원 표현, 전역 움직임 131차원, 둘을 결합한 2179차원 위에 각각 새로운
4-class linear head를 학습했다. 전역 움직임은 전체 sequence에서 과거 3프레임 평활·25Hz
미분 후 기존 64프레임 window 순서에 맞췄다. 결측은 명시적인 유효성 mask로 유지했다.

세 모델은 같은 학습 표본·batch·class weight·SGD·50epoch·validation 선택 규칙을 공유한다.
전역 특징 표준화는 train에서만 학습했고 Backbone·ADL·J1은 동결했다. 소실된 세부 채널 정의,
유효성 규칙과 일부 optimizer 설정은 실행 전에 별도로 명시했으며 과거 성능에 맞추지 않았다.
동일한 131차원이라도 과거 구현과 특징 의미가 같다고 가정할 수 없다는 한계가 있다.

497개 sequence, 8,091,357프레임에서 생성한 1,007,723개 window의 특징을 검증했다.
Train/validation/test/OOD는 각각 609,183/106,680/219,896/71,964개다.
특징 전수 재계산·표본 순서·인과성 검사, 150개 epoch의 validation metric 독립 재계산,
선택 모델 재추론과 CPU 비교를 통과했다. 소규모 사전 검사는 성능 근거에서 제외했다.
이번 test/OOD 평가는 validation 선택 잠금 이후 수행했지만, 데이터에는 이전 프로젝트 진단
이력이 있으므로 처음 보는 평가 자료라고 주장하지 않는다.
