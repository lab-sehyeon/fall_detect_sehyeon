# RGB·외부 평가 입력 검증

- 문서 ID: `DOC-20260928-rgb-data-preparation-R2`
- 기준일: 2026-09-28
- 상태: `completed` — 초기 입력 검사, 정합 수정은 후속 연구로 분리

후속 [좌표·시간축 정합 및 학습](2026-09-28_global_motion_training_shared.md)에서 공식리사이즈
근거에 따른SAFER공간정합과OOPS영상끝구간제한을 완료했다. 아래는수정전검사결과이며,
원자료와초기진단결과를보존한별도revision으로이어진다.

OOPS-Fall 원영상818개와 시간 구간 라벨4,022행을 확보했다. 전체276,539프레임을 정상적으로
읽었으며 비디오 길이는 총 약2.647시간이다. 배경 `other`와 구체 행동의 겹침2건에서
배경24.033초만 제거했다. 정규화 후4,021행, 겹침0건이며 낙상914행은 유지됐다.
공식 라벨 원본은 변경하지 않았다.

SAFER OOD 원영상30개는 확보·공식 체크섬 검증을 완료했다. 첫·마지막 프레임 검사를 기본으로
했고6개 영상에는 전체 프레임 검사를 적용했다. Normal467개 원영상까지 모두 확보한 상태는 아니다.

SAFER 전체497개·8,091,357프레임의 공식 pose 자료에 bbox·2D좌표·confidence가 있음을 확인했다.
별도 정의한 좌표 검사에서 `corner_xywh` 해석이 지지됐다. 따라서 전역 움직임 입력 준비를 위해
모든 normal RGB 영상을 먼저 확보할 필요는 없지만, 결측 mask와 특징 정의의 검증은 남아 있다.

## 학습 전 남은 정합

- OOPS36개는 라벨 끝 시간이 비디오 트랙보다 약0.034~0.048초 길지만 파일 전체 길이 안에 있다.
  비디오 프레임 수는 트랙 길이와 일치한다. 영상·파일·25fps 입력 사이의 끝 구간 처리 규칙을
  확정해야 하므로 기존 시간축 검사를 통과한 것으로 바꾸지 않았다.
- SAFER OOD30개의 프레임 수는 공식 pose 자료와 일치하지만25개는 기록된 이미지 해상도와
  실제 영상 해상도가 다르다. RGB와 기존 pose를 결합하기 전 좌표 대응 검증이 필요하다.

현재 단계는 입력 준비이며 모델 학습·RGB 전체 추론·외부 성능 평가 완료를 의미하지 않는다.
특히 `stand_up` annotation과 회복 episode는 다른 단위다. 과거 회복299개라는 수치에 맞춰
annotation을 임의 제외하지 않고 episode 정의를 별도로 복구해야 한다.
기존 OOPS 진단 이력이 있으므로 후속 결과도 최초 비공개 평가처럼 표현하지 않는다.
