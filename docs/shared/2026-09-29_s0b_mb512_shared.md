# S0-B 마이크로배치 변경

- 문서 ID: `DOC-20260929-s0b-mb512-R2`
- 기준일: 2026-09-29
- 상태: `paused` — 동기식 병렬 실행으로 학습상태 계승

현재는 [병렬 계승 실행](2026-09-29_s0b_acceleration_shared.md)에서학습중이다.
이실행은첫epoch373760개window에서상태를넘겼으며아래는이전진행이력이다.

마이크로배치를 128에서 512로 변경하고 누적 횟수는 8에서 2로 줄인다. 실질 학습 배치1024,
모델·데이터 순서·학습률·12epoch·평가 및 채택 기준은 유지한다. 기존 학습 상태를 계승하는
별도 실행으로 구분한다. 첫 epoch의217,088개 window를 처리한 상태를 계승하며,
이미 학습한 구간을 반복하지 않는다. 초기 validation 동등성 증거와 학습 상태 보존 검산,
새 구성의 제한 학습·동결 모델 불변 검증을 통과해 후속 학습을 재개했다.

이는 학습 도중 계산 묶음 크기가 바뀐 실행이다. Dropout 난수 배정과 부동소수점 연산 순서가
달라질 수 있으므로 기존 실행과의 bit-exact 동등성은 주장하지 않는다. 성능을 보고 조건을
조정한 실험이 아니며 정식 모델 성능 결과는 아직 없다.
