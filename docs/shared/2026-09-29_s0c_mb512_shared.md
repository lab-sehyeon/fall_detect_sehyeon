# S0-C 비교 입력 갱신

- 문서 ID: `DOC-20260929-s0c-mb512-R2`
- 기준일: 2026-09-29
- 상태: `planned`

현재대기입력은 [병렬계승 B 결과](2026-09-29_s0c_acceleration_shared.md)로갱신됐다.
아래방법은유지하며아직정식비교결과는없다.

[S0-B 마이크로배치512 계승 실행](2026-09-29_s0b_mb512_shared.md)이 완료되면 S0-A와 같은
44가지 조건으로 비교한다. [기존 C 방법](2026-09-29_s0c_reconstruction_shared.md)의
EMA·지속시간·margin, 채택 기준, validation 기반 선택, 선택 후 test/OOD 평가 및 지연 진단은
변경하지 않는다. 입력 B 실행의 계보만 달라졌으며 아직 비교 결과는 없다.
