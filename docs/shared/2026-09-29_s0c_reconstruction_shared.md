# S0-C 상태 안정화 비교

- 문서 ID: `DOC-20260929-s0c-reconstruction-R2`
- 기준일: 2026-09-29
- 상태: `planned` — 구현·기능 검사 완료, S0-B 완료 후 실행 대기

현재는 [마이크로배치512 S0-B 입력](2026-09-29_s0c_mb512_shared.md)을 기다린다.
아래 비교 방법과 채택·선택·평가 규칙은 변경하지 않는다.

고정 S0-A/S0-B에 동일한44개 조건을 적용해 temporal correction과 후처리 효과를 분리한다.
각 모델에서 raw, EMA(.5/.7/.85), EMA와 최소지속시간(3/5/8프레임)·확률차이(0/.05)를 비교한다.
EMA alpha는 이전 posterior 가중치로 사전 정의한다. 과거 출력은 소급 수정하지 않는다.

각 모델의 raw 대비 validation Macro-F1하락≤0.5%p, fall recall하락≤2%p, 상태전환≥25%감소를
모두 만족한 후보 중 SegmentF1@50→Edit→Macro-F1로 선택하고 그후test/OOD를 평가한다.
통과 후보가 없으면 diagnostic만 보고하며 채택하지 않는다. 보정 학습은 하지 않는다.

선택된 상태 출력의 전이 지연·누락·조기 전환도 별도 진단한다. 이는 선택 지표가 아니며
상태 안정화가 회복 사건 검출이나 온라인 causal 성능 향상과 같다는 주장은 하지 않는다.
소실된 decoder 세부를 사전 명시한 별도 실험으로, [기존 기록](2026-09-03_09_state_recovery_decoder_shared.md)의
EMA0.7 선택을 이번 실험에 미리 적용하지 않는다.

후속 실행은 S0-B 무결성 확인→제한 검증→전체44조건 비교→선택 후 평가 순으로 연결했다.
기능 검사는 통과했지만 실제 두 모델의 전체 비교 결과는 아직 없다. 선행 실험이 중단되면
이 비교도 시작하지 않는다. S0-B의 성능 채택 여부와 실험 무결성 통과 여부는 구분한다.
