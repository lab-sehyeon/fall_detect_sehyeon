# 현재 모델에 적합한 추가 벤치마크 조사

- 문서 ID: `DOC-20261002-additional-benchmark-search-R1`
- 기준일: 2026-10-02
- 상태: `completed` — 후보 조사·공식 메타데이터 대조 완료. 이 조사에서 새 모델 추론은 수행하지 않음.

## 1. 결론

새로운 데이터셋 중에서는 **TST Fall v2를 스켈레톤 분류부 평가 후보로 우선 검토**한다.
RGB에서 관절을 추정하는 단계를 거치지 않고 Kinect의 3D 관절을 이용할 수 있기 때문이다.
공식 시험 목록과 기존 논문 보고값을 활용하는 RGB 시스템 비교에서는 **Le2i-CS와 CAUCA-CS**가
우선 후보다. 입력 특성에 따른 선정이며, 새 후보에서 높은 점수가 실제로 측정됐다는 뜻은 아니다.

Exa로 세 방향의 검색 결과 30건을 조사하고 URL 중복을 제거한 25건에서 후보를 추렸다.
수치와 평가 조건은 데이터 저자의 배포 자료, 논문 원문, 공식 벤치마크로 확인했다.

| 대상 | 지금 확인된 근거 | 현재 판단 |
| --- | --- | --- |
| Le2i 기존 127영상 평가 | 현행 G0 이벤트 F1 **90.710%**, G2 **90.608%**, 전체 분모·독립 검산 확인 | 현재 모델의 높은 성능이 확인된 조건 |
| CAUCA 기존 100영상 진단 | **기존 기록 기준** G0 F1 **95.146%**, G2 **93.878%** | 높은 성능의 선행 단서. 현행 모델의 새 결과는 아님 |
| TST Fall v2 | Kinect v2 관절·11명·264시퀀스 | 새로운 native 3D 평가 후보. 우리 모델 점수 미측정 |
| OmniFall Le2i-CS / CAUCA-CS | 고정된 시험 목록·구간 정답·논문 비교값 확보 | 기존 결과와 다른 공식 구간 평가가 필요 |

Le2i의 수치는 [현재 모델 평가](2026-10-02_le2i_current_evaluation_shared.md),
CAUCA의 과거 수치는 [기존 외부 진단](2026-09-03_07_caucafall_shared.md)에 근거한다.
TST 구성은 [저자 배포 설명](https://ieee-dataport.org/documents/tst-fall-detection-dataset-v2)에 근거한다.

## 2. 모델과의 관련성

### TST Fall v2: 새 데이터에서 스켈레톤 분류부 확인

TST는 Kinect v2의 25관절과 프레임 시각을 제공한다. 11명이 네 가지 일상동작과 네 가지
낙상동작을 각각 세 번 수행한 264시퀀스다. 의도적으로 눕는 동작과 낙상이 함께 있어
단순히 누운 자세만으로 낙상을 구분하는지 살펴볼 수 있다.
[공식 데이터 설명](https://ieee-dataport.org/documents/tst-fall-detection-dataset-v2)

현재 모델의 FU 경로처럼 관절 입력에서 특징을 얻는 평가를 구성할 수 있다는 점이 장점이다.
이는 **입력 형태의 관련성에 대한 추론**이며 성능 향상이 확인됐다는 의미는 아니다.
관절 순서·좌표계·정규화·시간 집계·사용할 분류기를 먼저 대조해야 한다.
RGB 검출과 자세 추정이 제외되므로 결과는 스켈레톤 분류부의 외부 전이를 평가한다.

기존 TST 논문은 있지만 평가 계약이 통일돼 있지 않다. Seredin 등의 2019년 논문은
피험자를 한 명씩 제외하는 LOPO 평가를 사용한다. 본문의 전체 시퀀스 정확도는 **91.7%**이며,
95.8%를 전체 LOPO 성능으로 가져오면 안 된다. 현재 고정 모델의 무학습 외부 평가와
TST 피험자 열 명으로 학습한 결과도 구분해야 한다.
[논문 본문](https://isprs-archives.copernicus.org/articles/XLII-2-W12/189/2019/isprs-archives-XLII-2-W12-189-2019.pdf)

### Le2i: 현재 높은 결과와 공식 비교를 구분

현재 G0는 기존 계약의 전체 127영상에서 TP 83, FP 4, FN 13을 기록했다.
품질 탈락한 낙상 11개도 FN에 포함한다. 25fps 기준의 64프레임 연속 창을 사용하며,
경보를 정답 시작 0.5초 전부터 종료 3초 후까지 일대일 매칭한 **이벤트 F1**이다.
이는 높은 성능을 뒷받침하는 실제 결과이지만, 구간당 한 번 분류하는 OmniFall F1과는 다르다.
[평가 조건과 결과](2026-10-02_le2i_current_evaluation_shared.md)

OmniFall Le2i-CS는 38영상·203구간이다. 기존 127영상과 이름으로 일치하는 영상은 22개이며
Lecture_room·Office 등의 추가 장면도 포함된다. 기존 이벤트 결과로 공식 구간 점수를
대체할 수 없다. 공식 평가의 별도 입력 준비와 사전 검증은
[Le2i-CS 진행 문서](2026-10-02_omnifall_le2i_benchmark_shared.md)에 기록되어 있다.

### CAUCA: 과거의 긍정적 단서를 현행 조건에서 재확인

과거 100영상 진단의 G0 F1 95.146%는 이 데이터에서 모델이 잘 동작했던 기록이다.
이번에 해당 원시 예측을 재검산하거나 현행 가중치로 평가한 것은 아니므로 현재 점수로
표기하지 않는다. 공식 CAUCA-CS의 시험은 19영상·47구간이며 평가 단위도 다르다.
또한 CAUCA는 여러 전처리를 반복 진단한 개발성 외부 데이터라는 이력을 유지한다.
[기존 CAUCA 기록](2026-09-03_07_caucafall_shared.md)

## 3. 공식 시험 메타데이터를 직접 대조한 결과

고정된 공식 배포본의 시험 목록, 전체 라벨 중 해당 영상의 주석, 배포된 시험 테이블을
대조했다. 영상 집합과 구간 라벨·시각·피험자·카메라 정보가 일치했다.
아래는 새로 집계한 **시험 통계**이며 모델 성능이 아니다.
[공식 고정 배포본](https://huggingface.co/datasets/simplexsigil2/omnifall/tree/83572a37b9e3081df8c06a56874b1d1f2a19386c)

| 공식 CS 시험 | 영상 | 구간 | 낙상 / 기타 | 시험 피험자 수 | 낙상 길이 중앙값 | 2.52초 미만 낙상 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Le2i | 38 | 203 | 22 / 181 | 2 | 1.969초 | 18 / 22 |
| CAUCA | 19 | 47 | 9 / 38 | 2 | 2.400초 | 5 / 9 |
| UP-Fall | 264 | 522 | 114 / 408 | 4 | 2.005초 | 92 / 114 |
| EDF | 2 | 128 | 16 / 112 | 1 | 2.889초 | 2 / 16 |
| OCCU | 2 | 101 | 16 / 85 | 1 | 1.140초 | 16 / 16 |

2.52초는 25fps에서 64프레임의 첫 프레임과 마지막 프레임 사이 시간이다.
구간 전체를 64장으로 균등 표본화하면 길이에 따라 동작 속도가 달라져 보일 수 있다.
다른 데이터셋을 선택해도 이 시간 처리 차이가 자동으로 해소되지는 않는다.

EDF는 낙상 길이가 상대적으로 길어 시간 처리 영향을 확인할 보완 후보이나 시험 피험자가
한 명이다. OCCU는 낙상 말미의 완전 가림을 다루는 데이터로, RGB 자세 추정이 필요한 현재
시스템의 강점을 확인하는 첫 대상으로는 우선순위가 낮다.
[EDF·OCCU 저자 설명](https://zenodo.org/records/15494102)

UP-Fall에는 시작과 종료가 모두 0초인 비낙상 구간 두 개가 공식 주석에 존재한다.
현재 집계는 이 두 개를 포함한다. 공식 표본화는 같은 시각을 반복하는 동작이 정의돼 있으므로
후속 평가에서 임의로 제거하지 않고 실제 영상 해독·품질 판정과 함께 확인해야 한다.

## 4. 기존 논문 보고값을 사용하는 비교

아래 수치는 OmniFall v3 Table 3의 **Fall F1(%) 보고값**이다. 비교 모델을 재실행한 결과가 아니다.
앞의 네 열은 대상 데이터의 명시적 학습을 포함하지 않는 설정이고, 마지막 두 열은 대상 데이터의
학습 분할을 포함한다. 학습자료가 다른 설정을 같은 조건의 성능 순위로 해석하지 않는다.
[OmniFall 논문 Table 3](https://arxiv.org/html/2505.19889v3)

| 시험 | Qwen3-VL ZS | InternVL3.5 ZS | VideoMAE CMDF 학습 | VideoMAE 합성 학습 | VideoMAE Staged 학습 | VideoMAE Staged+합성 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Le2i | 16.0 | 38.7 | 79.1 | 74.3 | 100.0 | 97.8 |
| CAUCA | 85.7 | 78.3 | 80.0 | 77.8 | 94.1 | 100.0 |
| UP-Fall | 27.4 | 68.8 | 21.1 | 76.2 | 95.6 | 96.9 |
| EDF | 0.0 | 34.8 | 9.5 | 38.7 | 77.8 | 77.8 |

우리 모델의 공식 시험 점수는 이 조사에서 생성하지 않았다. **Le2i 이벤트 F1 90.710%를
위 표의 79.1%와 직접 비교하여 기존 모델보다 높다고 주장할 수 없다.**

EDF는 추가 확인이 필요하다. 현행 시험 메타데이터는 낙상 16개인데 논문 일부 행의 recall
35.3%·82.4%는 16개를 고정 분모로 한 단일 집계로 재구성되지 않는다. 평균 방식이나 배포본
차이인지 확인되기 전에는 해당 보고값과 완전히 동일한 시험을 재현했다고 주장하지 않는다.

## 5. 우선순위와 남은 범위

| 우선 검토 | 목적 | 평가 전에 확인할 내용 |
| --- | --- | --- |
| TST Fall v2 | 새 native 3D 데이터로 스켈레톤 분류부 확인 | 공식 원본·사용 조건, 관절 변환, 시퀀스 평가 계약, 비교 논문 조건 |
| Le2i-CS | 현재 높은 이벤트 결과가 공식 구간 분류에서도 유지되는지 확인 | 별도 진행 중인 공식 영상 준비·검증 후 전체 203구간 평가 |
| CAUCA-CS | 과거 높은 진단 결과를 현행 고정 모델·공식 시험으로 재확인 | 전체 47구간 계약과 개발 사용 이력 명시 |
| EDF-CS / UP-Fall-CS | 시간 길이·피험자 규모가 다른 보완 평가 | EDF 비교 분모, UP-Fall 0초 주석·영상 처리 확인 |

Improved 3D UP-Fall은 추정된 33관절, 5명, 충돌 순간의 정답, 짧은 영상 제외라는 다른 조건을
사용하므로 원래 UP-Fall 평가의 대체재로 채택하지 않았다.
[저자 저장소](https://github.com/Tresor-Koffi/3D_skeletons-UP-Fall-Dataset)
Shinolab의 Kinect 데이터는 비낙상 보행이 피험자 한 명에만 있고 낙상 안내 표시를 실제 낙상
정답으로 볼 수 없어, 그대로 사용하는 직접 비교 후보에서 제외했다.
[저자 데이터 설명](https://github.com/shinolab/Fall-Dataset)

MCFD의 보류 상태와 기존 GMDCSA F1 37.037%, URFD F1 58.824%는 그대로 유지한다.
새 결과를 얻으면 전체 시험과 처리 실패를 포함해 추가하고, 서로 다른 평가 단위는 분리해서 보고한다.
[GMDCSA 결과](2026-10-02_omnifall_gmdcsa_benchmark_shared.md),
[URFD와 근거 검토](2026-10-02_paper_evidence_review_shared.md)

표의 데이터는 [후보 시험 통계 CSV](2026-10-02_additional_benchmark_candidates.csv)와
[기존 논문 보고값 CSV](2026-10-02_additional_benchmark_reported_results.csv)에도 정리했다.
