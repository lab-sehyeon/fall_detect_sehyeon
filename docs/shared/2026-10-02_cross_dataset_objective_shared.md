# 학습에 사용하지 않은 데이터셋에서의 성능 목표

- 문서 ID: `DOC-20261002-cross-dataset-objective-R1`
- 기준일: 2026-10-02
- 상태: 검토 `completed`, 개선 실험 미실행

목표는 우리 모델과 비교 모델 모두 시험 데이터셋을 태스크 학습에 포함하지 않은 조건에서,
동일한 시험·정답·평가 단위로 높은 성능을 확인하는 것이다. 높은 외부 성능은 아직 충분히
입증되지 않았다. 결과가 잘 나온 데이터만으로 일반화를 주장하지 않고 완료된 전체 결과를 유지한다.

## 현재 비교의 조건

현재 J1은 SAFER/FU, G0는 SAFER에서 학습됐다. CAUCA·Le2i·GMDCSA를 이용한 이번
타깃 학습이나 임계값 보정은 없었다. 비교표의 VideoMAE-CMDF와 VideoMAE-Synthetic 역시
해당 타깃을 명시적 태스크 학습에 포함하지 않은 보고 설정이다. 따라서 현재 낮은 값은
이러한 외부 전이 조건에서 관측된 결과다. 모든 모델의 사전학습 자료 중복까지 배제한 것은 아니다.
[평가와 학습조건 비교](2026-10-02_omnifall_cauca_benchmark_shared.md)

다만 최근 구간 비교에서는 우리 모델의 입력도 달라졌다. 원래는 실제 시간축의 연속64프레임을
처리하지만, 구간 비교에서는 서로 다른 길이의 정답 동작을64장으로 늘리거나 줄이고 추적·3D
처리를 구간마다 다시 시작했다. 공식 로더의 모드라는 사실만으로 이 처리가 원래 모델에
적합하다고 볼 수는 없다. 현재 구간 점수를 구현된 연속영상 모델의 유일한 성능으로 해석하지 않는다.
[입력 차이 분석](2026-10-02_omnifall_error_diagnosis_shared.md)

## 분류기만 개선할 때의 한계

현재 품질 거부를 그대로 유지하고, 나머지를 분류기가 모두 맞힌다고 가정했다.
전체 낙상 수를 P, 그중 품질 통과한 낙상 수를 U라 하면 오경보가 없어도 F1 상한은
`2U / (P + U)`다.

| 평가 | 전체 낙상 | 품질 거부 낙상 | 현재 F1 | 같은 거부를 유지할 때의 F1 상한 |
| --- | ---: | ---: | ---: | ---: |
| CAUCA 구간 | 9 | 5 | 50.00% | **61.54%** |
| Le2i 구간 | 22 | 9 | 53.33% | **74.29%** |

이는 새 실험 결과가 아닌 조건부 산술 상한이다. **현재 전단과 품질 판정을 유지한 채
분류기만 재학습해서는 이 상한을 넘을 수 없다.** 품질 기준을 완화하면 오경보도 늘 수 있으므로,
단순히 실패를 통과시키면 성능이 개선된다는 뜻은 아니다.

## 후속 검증의 순서

1. 원래 모델의 시간축·문맥·관절 입력을 유지하는지 확인한다. 구간 분류와 연속 사건 검출은 구분한다.
2. 학습·검증 자료에서 사람 검출·자세 추정의 실패 원인을 점검하고, 필요한 변경을 검증한다.
3. 모델·전처리·품질 정책·판정 규칙을 고정한 뒤 아직 해당 모델의 결과를 확인하지 않은 외부 시험을 평가한다.
4. 비교 모델도 타깃 학습 미포함인 설정을 사용하고, 동일 평가 단위의 수치만 직접 비교한다.

이미 결과를 본 Le2i·CAUCA·GMDCSA에서 이후 수정의 효과를 확인하면 후속 진단으로 표시한다.
Le2i의 연속 사건F178.95%와 구간F153.33%는 입력뿐 아니라 평가 규칙도 달라
순수 모델 개선량으로 표현하지 않는다.
[연속 처리 결과](2026-10-02_omnifall_le2i_continuous_shared.md)

이번 검토에서 새 학습이나 품질 기준 변경은 수행하지 않았다. 실제 개선의 크기와 새 외부
시험 성능은 아직 확인되지 않았으며, 높은 최종 점수를 보장할 수는 없다.
