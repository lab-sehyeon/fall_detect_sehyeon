# J1과 G0 단독 구조와 성능 평가

- 문서 ID: `DOC-20261002-j1-g0-only-R1`
- 기준일: 2026-10-02
- 상태: `completed`

앞으로 낙상 분류 경로는 **고정 DSTE → 학습된 J1 어댑터 → G0 분류기**를 사용한다. 전역 움직임 분기와 G1·G2는 현재 사용 경로에서 제외하고 기존 비교 연구 결과로 보존한다. Le2i와 URFD의 세 평가 범위에서 새 추론과 독립 검산을 완료했으며, 모든5555개 창의 특징과 G0 출력이 이전 G0와 완전히 일치했다. 이번 결과는 성능 개선이 아니라 단독 구조의 동등성과 성능 확인이다.

## 구조와 학습 범위

영상에서 사람 검출·2D 자세 추출·품질 검사를 거쳐3D 관절을 만들고, 25관절 형식의64프레임 창을 DSTE에 넣는다. DSTE의2048차원 특징을 J1이 보정하고 G0가 other/fall/lie_down/lying_down으로 분류한다. 25fps·stride8과 기존 품질 기준을 유지한다. 거부된 영상은 무경보로 처리하되 평가 분모에 남긴다.

DSTE와 영상 전처리 모델은 사전학습 가중치를 고정한다. J1은 SAFER·FU로 학습한 최종 어댑터이며, G0는 그 표현 위에 SAFER로 별도 학습한 분류기다. 추가 학습이나 시험 데이터에 맞춘 선택·보정은 하지 않는다. 기존 ADL 분류기와 J1 학습용 데이터셋별 head도 현재 낙상 판정에서는 실행하지 않는다.

## 평가 조건과 검증

Le2i 공식 시험38영상, 기존 Le2i127영상, URFD70영상에서 검증된 자세 입력을 재사용하고 DSTE·J1·G0를 새로 추론했다. Le2i는 기존 낙상 사건 지표, URFD는 기존 영상 단위 분류 지표를 유지했다. 두 Le2i 범위는22영상이 겹치므로 합산하지 않으며 서로 독립된 두 데이터셋도 아니다.

미사용 분기를 제거한 모델과 이전 모델의 DSTE 특징, J1 특징, G0 출력은 전수 비교에서 차이가0이었고, 창별 분류와 사건/영상 판정도 모두 같았다. CPU에서 어댑터·분류기를 다시 계산한 판정도 일치했으며 별도 사건/분류 지표 검산을 통과했다. 이번 검증은 전체 RGB 전처리의 새 실행이나 미관측 데이터 평가를 뜻하지 않는다. 양방향3D 처리와 영상 전체 품질 판정이 포함돼 엄밀한 실시간 성능 주장도 하지 않는다.

## 확정 성능

| Le2i 공식38영상 | 사건 | 15 | 1 | 7 | 93.75% | 68.18% | 78.95% |
| 기존 Le2i127영상 | 사건 | 83 | 4 | 13 | 95.40% | 86.46% | 90.71% |

URFD는 TN34, specificity85%, accuracy70%, AP71.11%다. Le2i의 사건 지표에는 영상 분류의 TN/accuracy를 적용하지 않는다. 표의 범위는 시험 구성·주석·평가 단위가 달라 합산하거나 직접 우열로 비교하지 않는다.

## 남은 오류와 해석

- Le2i 공식38영상은29영상이 품질 검사를 통과했다. 미탐7건은 모두 품질 거부 영상이다.
- 기존 Le2i127영상은116영상이 통과했다. 미탐13건 중11건은 품질 거부이고,2건은 통과 후 사건 미탐이다.
- URFD70영상은45영상이 분류됐다. 미탐15건 중11건은25fps 변환 후 길이가64프레임 미만이어서 기존의 padding 없는 입력 조건에 따라 처리되지 않았다. 나머지4건은 분류 미탐이다. 짧은 영상 문제를 사람 검출 실패와 혼동하면 안 된다.

J1+G0만 남겨도 기존 G0 성능은 보존됐지만, 앞단의 품질 거부와 짧은 입력 문제는 그대로 남는다. 품질 기준 완화나 padding 변경을 이번 결과에 섞지 않았다. 이들을 검토하려면 현재 기준 결과를 보존한 별도 실험이 필요하다. 새 학습이나 모델 선택을 하지 않았으므로 결과를 새로운 일반화 성능 향상으로 표현하지 않는다.
