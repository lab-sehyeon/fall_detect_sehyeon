# CAUCA-CS 공식 시험 구간 비교

- 문서 ID: `DOC-20261002-omnifall-cauca-benchmark-R1`
- 기준일: 2026-10-02
- 상태: `completed` — 전체 시험·독립 검산 완료

현재 고정 모델의 CAUCA-CS **Fall F1은50.00%, recall은33.33%**였다.
낙상9개 중3개를 검출하고6개를 놓쳤다. 미탐6개 중5개는 자세 품질 기준 미통과,
1개는 품질 통과 후 분류 오류였다. 이번 공식 구간 평가에서는 비교 모델보다 낮은 결과를 보였다.

## 평가 조건

현재 고정 모델을 공식 CAUCA-CS 시험19영상·47구간에 적용한다. 낙상9구간과 기타38구간을
모두 포함하고, OmniFall 논문 Table3의 Fall-vs-rest 보고값과 비교한다.
[공식 시험 목록](https://huggingface.co/datasets/simplexsigil2/omnifall/blob/83572a37b9e3081df8c06a56874b1d1f2a19386c/splits/cs/caucafall/test.csv),
[기존 모델 보고값](https://arxiv.org/html/2505.19889v3)

완료된 Le2i·GMDCSA 구간 평가와 같은 입력·모델 계약을 사용한다. 공식 변환 영상의 각
정답 구간에서64프레임을 균등 표본화하고, 자세 추정과 고정 DSTE/J1/G0를 적용한다.
타깃 데이터로 추가 학습·임계값 보정·모델 선택을 하지 않는다. 품질 미통과 구간은
무경보로 처리하고 전체 분모에 포함한다. 이 입력 방법은 원래25fps 연속영상 사건 검출과 다르다.

비교는 같은 시험 구간·정답·지표에 대한 시스템 비교이며 학습자료와 입력 표현은 모델마다
다르다. 다른 모델 수치는 논문의 보고값으로 표시한다. CAUCA는 과거 개발 진단에 사용됐으므로
완전히 미사용인 외부 시험이라고 주장하지 않는다. 과거100영상 진단 점수와 이번 구간
분류 점수도 직접적인 성능 증감으로 해석하지 않는다.

원본19영상을 확보해 저자 배포본과 대조하고 변환·입력 검사·예측·독립 검산을 완료했다.
학습된 가중치는 기존 Le2i 구간 평가와 동일하다. 현재 모델은4클래스 분류기이므로,
논문의16클래스 전체 성능 대신 `fall`만 양성인 이진 지표로 비교한다.

원본은 Mendeley v4의 제공 AVI를 사용했다. 실제 시험 AVI는20fps·720×480이며,
제공된 PNG 프레임을 새 영상으로 재조립하지 않았다. 저자의 변환 조건과 실제 영상 시각을
유지한 뒤 각 GT구간을 균등하게64장으로 읽었다. 이는 촬영 장비 설명에 기재된23fps와
구별되는 실제 배포 영상의 속성이다.
[공식 원본](https://data.mendeley.com/datasets/7w7fccy7ky/4),
[저자 영상 변환](https://github.com/simplexsigil/omnifall-helper-scripts/blob/eb1443c1035ecdfbd15598dec16fae6aca71e7ea/video_conversion/caucafall.sh)

47구간의 입력3,008장을 순차 원영상 해독 결과와 대조했다. 반복 프레임을 포함하는 구간은
25개이고 고유 프레임 수는 최소11개다. 가장 가까운 원프레임을 선택하는 과정의 GT경계
차이는 최대 약20밀리초다. 구간·주석을 제외하거나 결과에 맞게 변경하지 않았다.

## 기존 모델과의 비교

| 모델 | 학습 조건 | Recall | Specificity | Fall F1 |
| --- | --- | ---: | ---: | ---: |
| **현재 DSTE + J1 + G0** | SAFER/FU J1, SAFER G0 | **33.33%** | **100.00%** | **50.00%** |
| Qwen3-VL-8B | Zero-shot | 100.0% | 92.1% | 85.7% |
| InternVL3.5-8B | Zero-shot | 100.0% | 86.8% | 78.3% |
| VideoMAE-K400 | CMDFall-CS | 66.7% | 100.0% | 80.0% |

첫 행은 이번 직접 실행·독립 검산값이고 나머지는
[OmniFall v3 Table3 보고값](https://arxiv.org/html/2505.19889v3)이다.
앞의 네 비교 설정은 CAUCA를 명시적 타깃 학습에 포함하지 않는다. 사전학습 자료까지의
완전한 중복 배제를 입증한 의미는 아니다. 모델별 학습자료와 입력 표현·시간 표본화가 다르다.
CAUCA 학습 분할을 포함하는 VideoMAE OF-Staged와 Staged+Synthetic의 보고 F1은
94.1%,100.0%이며, 외부 전이 비교와 구분해 [전체 비교 CSV](2026-10-02_omnifall_cauca_comparison.csv)에 포함했다.

## 실패 원인별 집계

전체 confusion count는 **TP3 / FP0 / FN6 / TN38**이다. Precision100%,
accuracy87.23%, AP52.86%이나, 실제로 검출한 낙상은9개 중3개뿐이다.

| 낙상9개에 대한 처리 | 개수 |
| --- | ---: |
| 자세 품질 통과 후 낙상으로 분류 | 3 |
| 자세 품질 통과 후 비낙상으로 분류 | 1 |
| 자세 품질 미통과로 무경보 처리 | 5 |

총40구간이 품질 기준을 통과했고7개는 통과하지 못했다. 통과하지 못한 낙상5개는 모두
검출·자세 coverage0.8 기준에 미달했다. `FallRightS9`, `FallSittingS9`, `FallLeftS9`,
`FallForwardS8`, `FallForwardS9`의 낙상 구간이다. 품질 통과 후 놓친1개는
`FallLeftS8`이고 `other`로 분류됐다.

품질을 통과한 구간만 계산한 F1은85.71%지만 **조건부 성능**이며 전체 F150.00%를 대체하지 않는다.
같은 품질 판정과 무경보 정책을 유지하면 분류기에 도달하는 낙상은4개뿐이므로
recall은 최대44.44%로 제한된다. 이 상한은 현재 처리 정책의 계산상 한계다.
품질 기준을 완화했을 때의 성능은 측정하지 않았다.

시험 피험자는 두 명이며, 피험자9의 낙상4개는 모두 품질 기준을 통과하지 못했다.
낙상 한 건의 판정 차이가 recall11.11%p에 해당하므로 작은 표본의 결과를 광범위한
환경·사용자 일반화 성능으로 확대하지 않는다.

## 완료된 세 데이터셋의 구간 비교

다음 표는 같은 Fall-vs-rest 구간 평가 단위의 F1(%)만 모았다. 이번에 CAUCA를 새로
실행했고 GMDCSA·Le2i는 완료된 평가와 검산 결과를 다시 확인해 연결했다.

| 시험 | 현재 모델 | Qwen3-VL ZS | InternVL3.5 ZS | VideoMAE CMDF | VideoMAE 합성 |
| --- | ---: | ---: | ---: | ---: | ---: |
| GMDCSA24-CS | 37.04 | 64.5 | 60.6 | 61.1 | 64.3 |
| Le2i-CS | 53.33 | 16.0 | 38.7 | 79.1 | 74.3 |

기존 모델 값은 모두 [동일 논문 Table3](https://arxiv.org/html/2505.19889v3)의 보고값이다.
현재 모델은 Le2i에서 두 zero-shot 모델보다 높은 F1을 기록했으나,
세 시험 모두 CMDFall·합성 데이터로 학습한 VideoMAE의 보고값보다 낮았다.
이는 해당 시스템·학습자료·평가 조건의 결과이며 구조 자체의 인과적 우열 검증은 아니다.

Le2i의 기존 연속영상 사건 F178.95%와127영상 사건 F190.71%는 평가 단위·정답·시험 구성이
달라 이 표에 섞지 않는다. 과거 CAUCA100영상 진단 F195.15%도 현행 공식 구간 점수로 재사용하지 않는다.

## 검증 범위와 연결 문서

공식 시험 목록·라벨·원본과 가공 영상·입력 프레임·시각·동결 가중치를 확인했다.
저장된 검출 후보에서 추적 선택과 품질 판정을 다시 계산하고,40개 고정 DSTE 특징에 대해
CPU로 adapter와 G0를 별도 계산해 모든 최종 클래스가 일치함을 확인했다.
독립 지표 계산도 TP/FP/FN/TN과F1/AP가 일치했다. 전체 backbone의 독립 재추론을
수행했다는 의미는 아니다. 타깃 학습·임계값 조정·모델 재선택은 수행하지 않았다.
