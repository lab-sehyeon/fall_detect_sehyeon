# 공개 저자 프로그램을 이용한 외부 평가 사전 검토

> 후속 정정: [원본 주석 전수 확인](2026-10-03_le2i_missing_annotation_search_shared.md)으로
> 아래3개의 시작·종료 번호를 확인했다. 정답이 없었던 것이 아니라 파일 중간에 위치했다.
> 130영상/99낙상 정답 목록은 확보됐으며 전체 재평가는 아직 미실행이다.

문서 ID: DOC-20261003-author-evaluation-feasibility-R1  
갱신일: 2026-10-03  
상태: 사전 검토 `completed`; 원본 프로그램 전체 평가 미실행

현재 비교 모델은 SAFER-Activities에서 학습한 공개 CNN1D, ST-GCN++, MS-G3D다.
기존 결과는 공개 모델·가중치를 공통 외부 평가 절차에 연결해 실행한 결과이며,
저자가 배포한 영상 처리·추론·채점 프로그램 전체를 실행한 결과와 구별한다.

[공식 평가 안내](https://github.com/safer-activities/SAFER-Activities/blob/994ed688ce9e491245ee96c1665e948c6ce6c74d/inference/README.md)는
ImViA(Le2i)용 CNN1D 및 PySKL 추론 프로그램과 별도 사건 채점 프로그램을 제공한다.
공개 프로그램은 사람 추적, 관절 보간·필터링, 48프레임 입력의 조밀한 분류를 수행한다.
낙상 예측을 구간으로 구성하고 15프레임 허용폭으로 정답 구간과 대응한다.
이 절차는 기존 공통 평가의 8프레임 간격 추론 및 경보 시점 매칭과 다르다.

확인한 재현 조건의 차이는 다음과 같다.

| 항목 | 확인 결과 |
| --- | --- |
| 포즈 추출 | 논문은 ViTPose-H를 기술하지만 공개 외부 추론 프로그램은 ViTPose-B 사용 |
| 평가 목록 | 논문은 130영상/99낙상; 보유 주석 중 공개 파서로 읽을 수 있는 범위는 127영상/96낙상 |
| 주석 실패 | 세 파일의 시작·끝 헤더 형식이 달라 공개 프로그램은 해당 입력을 건너뜀 |
| 기존 논문 수치 | 외부 평가 표에는 CNN1D와 PoseC3D의 결과가 보고됨; ST-GCN++/MS-G3D의 같은 표 결과는 없음 |
| 다른 외부 데이터셋 | 별도 입력·주석 연결이 필요한 확장 평가이며 원래 ImViA 평가 재현과 구별해야 함 |

논문의 대상 목록·포즈 설정·보고 결과는
[SAFER-Activities §3.2 및 §4.3](https://arxiv.org/html/2609.08038v2#S4.SS3)에 근거한다.
현재 확보 조건으로 공개 코드를 실행하더라도 논문 조건의 정확한 재현이라고 단정할 수 없다.

후속 평가는 공개 코드의 실행 조건과 유효 입력 목록을 먼저 고정하고, 원본 프로그램의 출력과
채점 결과를 검산하는 순서로 구성한다. 사용자 모델을 같은 표에 비교할 때도 시간축·채점 기준을
맞춰야 한다. 이번 사전 검토에서는 새 성능 수치를 측정하지 않았다.
