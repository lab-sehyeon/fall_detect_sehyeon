# Le2i 제외 3영상의 원본 낙상 정답 확인

기존127영상 평가에서 제외했던 세 영상의 낙상 시작·종료 번호를 확인했다.
해당 정답은 원본 주석 파일의 중간에 들어 있었다. 첫 두 줄만 읽는 처리 방식 때문에 제외됐으며,
정답 자체가 없는 파일은 아니었다.

[Le2i 공식 배포본](https://search-data.ubfc.fr/imvia/dl_data.php?file=101)에서 해당 주석을 직접 확인했다.
세 주석은 보유 원본과 내용이 완전히 같았고, 영상은 공식 배포 목록과 크기·CRC가 일치했다.
[공개 보완 기록](https://medium.com/diving-in-deep/fall-detection-with-pytorch-b4f19be71e80)의
세 시작·종료 번호도 원본 값과 동일했다. 새로 정답을 추정하거나 수동 주석을 만든 것이 아니다.

전체130개 주석을 재검사한 결과, 기존127개의 정답 값은 모두 유지되며 세 낙상을 추가해
**130영상·99낙상·31비낙상**의 정답 목록을 구성할 수 있다.
원래 주석을 보존하고 정수 두 줄의 위치만 정규화한 별도 입력 사본을 준비했다.

OmniFall에도 세 영상의 낙상 구간이 있으나 이는 자체 기준의 재주석이다.
이번 원본 정답 확인에는 다른 주석 체계를 혼합하지 않았다.

**기존 F1 90.71%는 계속127영상·96낙상 결과다.** 이번 작업에서130영상 성능을 새로 측정하지 않았다.
후속 실험에서는 복원된 전체 목록과 평가 규칙을 고정하고, 제외됐던 입력을 처리한 뒤 성능을 다시
계산해야 한다. 논문과 영상·낙상 개수가 같다는 사실만으로 모든 실험 조건의 동일성을 주장하지 않는다.
