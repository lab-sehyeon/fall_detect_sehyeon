# Le2i와 CAUCAFall 모델별 낙상 판정 사례

문서 ID: DOC-20261004-fall-demo-cases-R2

기준일: 2026-10-04. 상태: `completed`.

다섯 모델에 대해 Le2i와 CAUCAFall에서 각각 성공 사례 하나와 실패 사례 하나를 선정하여 총 20개 그림으로 정리했다. 실제 영상 프레임, 저장된 중간 출력, 기존 판정 결과를 사용했다. 생성형 이미지나 새 예측을 실험 근거로 사용하지 않았으며, 재학습이나 판정 기준 변경도 하지 않았다.

전체 그림 갤러리 (공개 사본 미포함), 20쪽 PDF (공개 사본 미포함), 전체 압축본 (공개 사본 미포함), 사례 표 (공개 사본 미포함)를 제공한다. 개별 PNG는 3200 × 2100 픽셀이며 그림의 설명은 영어다.

## 판정 단위와 선정 방법

성공은 낙상 영상이 낙상으로 분류된 영상 단위 TP다. 실패는 낙상 영상의 미탐 FN을 우선했고, 실제 분류 과정을 보여주기 위해 입력 처리가 완료된 사례를 먼저 선정했다. 시간별 경보가 있는 모델의 성공 사례는 정답 사건과 매칭된 경보가 있는 영상으로 제한하고, 추가 경보가 적은 순서와 영상 ID 순서로 결정했다. 실패 사례는 처리 성공 여부와 영상 ID 순서로 결정했다. X3D에는 시간별 판정이 없으므로 영상 판정만 적용했다.

사례는 모델별로 독립적으로 사후 선정했다. 동일한 성공·실패 영상이 모든 모델에 적용된 일대일 비교도, 무작위 표본도 아니다. 이 20개 그림의 성공 비율은 모델 성능 지표가 아니다. 전체 성능과 모델 학습 출처는 [외부 비교 종합 결과](2026-10-04_external_comparison_summary_shared.md)를 따른다.

FLASH에는 두 가지 예외가 있다. Le2i의 낙상 영상에는 영상 단위 FN이 없어, 비낙상 영상을 낙상으로 오판한 FP로 실패 사례를 대체했다. CAUCAFall의 FN은 모든 프레임에서 MediaPipe 포즈를 얻지 못한 입력 실패다. 후자의 분류기는 실행되지 않았으며 음성 점수가 출력된 것처럼 표시하지 않았다.

## 그림 읽는 방법

상단은 정답 낙상 구간 전·중·종료 근처·이후의 실제 프레임이다. Le2i FP에는 비낙상 영상의 서로 다른 시점을 표시했다. 프레임 번호는 0부터 시작하며, 정답 경계가 실제 프레임 시각과 일치하지 않으면 가장 가까운 프레임을 표시한다. 원본 화면의 비율은 유지했으며, 모델의 입력 리사이즈를 설명하는 패널은 해당 모델의 입력 비율을 따른다.

중단은 각 모델의 실제 경로다. ourmodel과 USDRL에는 저장된 2D 관절, 변환된 NTU25 관절, 골격 특징과 분류 점수를 표시했다. ourmodel은 고정된 골격 인코더와 잔차 어댑터, 4클래스 분류기를 사용한다. USDRL은 저자 인코더와 프로젝트에서 학습한 NTU60 분류기의 조합이며 저자가 배포한 완성형 낙상 분류기가 아니다. HFD는 공식 C3D와 재학습 SVM, FLASH는 재학습 HyperMamba와 외부 RGB 어댑터다. X3D는 저자 UDA 가중치의 RGB 입력 추론이다.

시간별 출력을 가진 성공 사례의 중간 패널은 매칭된 경보 시점을 보여준다. DSTE 계열 FN은 낙상 softmax 점수가 가장 높았던 창을, HFD FN은 SVM margin이 가장 높았던 clip을 표시한다. FLASH FP는 첫 경보 시점이다. 이 시점 선택은 설명용이며 영상 선정이나 판정 기준을 바꾸지 않는다. X3D는 실제 5개 입력 clip의 샘플 위치와 평균 logit만 보여준다.

하단은 정답 구간과 점수·경보의 관계다. 녹색 영역은 정답 낙상 구간, 주황색 점은 낙상 양성 출력, 빨간 세로선은 경보 시작이다. DSTE 계열의 시각은 기존 25 Hz 평가 시간축의 창 종료 시각이고, 나머지 시간별 출력은 원영상 시각을 따른다. 정답 사건과 경보는 기존 허용 범위인 정답 시작 0.5초 전부터 종료 3초 후까지 매칭한다. 이는 오프라인 출력 정렬이며 실시간 처리 지연이 아니다. 점을 연결한 선은 시각화이며 새 중간 시점 예측이 아니다.

## 해석 범위와 한계

- 영상 단위 TP에도 추가 경보가 있을 수 있다. 특히 FLASH의 Le2i 성공 그림에는 사건 매칭 TP 1개와 추가 경보 1개가 함께 존재한다.
- 사용자 모델과 USDRL의 판정은 각각 4개·60개 클래스의 argmax다. 낙상 확률 0.5를 일괄 임계값으로 사용하지 않았다. HFD margin과 FLASH logit도 확률로 바꾸어 표시하지 않았다.
- 색상 특징 격자는 실제 특징의 표시용 요약이다. DSTE는 32차원씩 평균하여 64개 bin으로, HFD는 64차원씩 평균하여 64개 bin으로 표시했다. 관심 영역, attention, 인과적 설명 또는 모델 간 동일 척도가 아니다.
- 관절 오버레이에서 점수 또는 visibility 0.2 미만의 점을 생략하는 것은 표시 전용이다. 모델 입력·품질 기준·판정에는 적용하지 않았다. 3D 그림은 추정·정규화된 좌표이며 실제 세계의 미터 단위 자세가 아니다.
- 관측된 실패 패턴은 보여주지만, 조명·카메라 시점·관절 품질이 실패를 유발했다는 인과적 결론은 이 그림만으로 내릴 수 없다.
- RGB 프레임은 비식별화된 자료가 아니다. 원 데이터셋의 이용 및 재배포 조건이 계속 적용되며, 이 사례 제작으로 공개 배포 권한이 새로 부여되는 것은 아니다.

원 프레임 해시와 저장된 점수를 대조하여 20개 사례의 입력·판정 일치를 확인했다. 그림은 기존 평가를 설명하는 정성 자료이며 전체 결과를 대체하지 않는다.
