# 최신 낙상 특화 모델의 외부 평가 준비 결과

- 문서 ID: `DOC-20261004-fall-specialized-baselines-R1`
- 기준일: 2026-10-04
- 상태: 취득·준비 검증 `completed`; 외부 평가 `paused` — 필수 원본 자산 누락

## 1. 평가 범위

최신 낙상 특화 모델을 이용해 기존 Le2i130개·CAUCA100개에서 사용자 모델과 비교하는
평가를 준비했다. 대상 데이터 추가 학습·판정 기준 조정 없이 저자 학습 모델을 사용하며,
같은 영상·정답·실패 포함 집계 조건을 유지한다. 일반 행동인식 모델은 이번 대상에서 제외했다.

## 3. 성능 평가를 진행하지 못한 이유

**FLASH와 DistillH-Mamba는 추론에 필요한 학습 가중치를 확보하지 못했다.** 학습 코드는
있지만 이것만으로 학습된 저자 모델의 성능을 측정할 수 없다. 이번에 조사한 공개 범위의
결과이며 다른 미공개·외부 배포가 전혀 없다는 의미는 아니다.

**STGCN-GRU-BiLSTM은 가중치가 로딩됐지만 입력을 동일하게 만드는 정보가 부족하다.**
원래 전처리는 학습 데이터에서 계산한 정규화 통계를 사용한다. 공개된 자료로 통계를
다시 계산하려면 그 자료가 해당 가중치를 학습한 자료와 같다는 확인이 필요하다. 저장소의
일부 학습 기록은72개 시퀀스를 나타내지만 공식 데이터는82개이며, 어느 기록이 배포
가중치에 대응하는지도 확정되지 않았다. 외부 시험 영상에서 새 통계를 계산하는 방식은
현재의 고정된 입력 조건을 바꾼다.

입력·출력의 추가 차이도 확인했다. FLASH/Distill의 공개 전처리는99개XYZ 좌표열 중
35개 열을 중복 선택하는 연산이어서 공개 데이터의 관절 설명과 대응을 확인해야 한다.
STGCN의 확보 모델은 시퀀스당1개 확률을 출력하지만 제공된 평가 코드는100프레임 라벨을
펼쳐 비교하는 부분이 있어 원본 평가 절차를 확정해야 한다. 이 발견은 배포물의 재현
제약이며 논문 결과 전체의 진위를 판단하는 근거로 확대하지 않는다.

## 4. 현재 결과와 다음 단계

**이번 작업에서 새 외부 영상 추론과 성능 집계는 수행하지 않았다.** 모델 파일 로딩과
입출력 검사 결과를 낙상 F1·정확도로 보고하지 않는다. 기존 사용자 모델과 비교 모델의
성능 기록은 유지한다.

다음 단계에는 저자의 최종 학습 가중치와 대응 정규화 통계, 정확한 source 구성과
전처리·출력 시각 정의가 필요하다. 이 자산이 확인되면 원본 모델 검증, source 동작 확인,
고정된230개 외부 영상 평가, 공통 지표 검산 순서로 진행할 수 있다. 별도 재학습이나
입력 규칙 변경을 선택할 경우에는 원저자 학습 모델 평가와 구분한 재현 실험으로 기록한다.
