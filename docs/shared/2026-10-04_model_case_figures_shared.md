# 같은 두 영상을 사용한 모델별 개별 사례 그림

다섯 모델에 대해 **모델 한 개와 사례 한 개를 한 장에 표시하는 그림**을 총 열 장 제작했다. Case 1은 Le2i `Coffee_room_01_014`, Case 2는 CAUCAFall `forward/FallForwardS9`다. 같은 사례에는 모델과 관계없이 동일한 네 프레임과 시각을 사용했다. 새 추론 없이 기존 점수와 판정을 그대로 표시했다.

## 모델별 그림

각 링크는 독립적인 PNG 이미지다. TP는 낙상 검출, FN은 낙상 미탐이며 영상 단위 판정이다.

## 그림 구성과 해석

상단은 모델 이름과 사례 식별자, 동일한 실제 네 프레임이다. 하단 왼쪽에는 해당 모델의 저장된 점수, 오른쪽에는 최종 영상 판정과 정답 구간, 사건 지표를 표시한다. 맨 아래에는 기존 판정 규칙과 처리 경로를 설명한다. 모든 그림은 영어 표기이며 제안 모델은 Ours로 통일했다.

Ours와 USDRL은 낙상 softmax 및 최대 비낙상 클래스 점수를 보여주며 argmax로 판정한다. HFD는 SVM margin, FLASH는 frame logit과 유효 포즈 조건을 반영한 양성 출력을 보여준다. 이 두 값은 보정된 확률이 아니다. X3D는 다섯 clip의 평균 logit에서 계산한 영상 전체 softmax를 표시하며, 시간별 판정과 사건 지표는 N/A다.

시간별 출력에서 빗금 영역은 GT 낙상 구간, 주황 세로선은 경보 시작, 파란 점은 실제 낙상 양성 출력이다. 연결선은 표시 보조이며 중간 시각의 새로운 예측이 아니다. 동일 모델의 두 사례는 같은 점수 축 범위를 사용하지만 서로 다른 모델의 점수를 같은 척도로 비교하지 않는다. GT 시작 0.5초 전부터 종료 3초 후까지의 기존 사건 매칭 규칙을 유지했고 오프라인 시각을 실시간 지연으로 해석하지 않는다.

Ours의 사건 TP/FP/FN은 두 사례 모두 1/0/0이다. FLASH는 두 낙상 영상을 모두 검출했지만 추가 사건 경보가 각각 2개와 4개다. 이를 영상 FN으로 바꾸지 않고 TP와 추가 경보를 구분했다. 두 사례 모두 다섯 모델의 입력 처리가 완료됐다.

## 논문 사용 범위

각 그림은 4296 × 2790픽셀, 600dpi PNG이며 벡터 글꼴 PDF와 SVG도 제공한다. 7.16인치 폭 기준 최소 글자는 8.5pt다. 개별 PDF 링크는 갤러리에서 확인할 수 있다. 원본 RGB의 장면 정보는 생성하거나 복원하지 않았다.

이 두 영상은 Ours 성공과 일부 비교 모델의 미탐을 관찰한 뒤 사후 선정한 사례이며 대표 표본이나 전체 우월성의 근거가 아니다. [사례 선정과 전체 평가 설명](2026-10-04_ours_success_comparison_shared.md)을 함께 사용한다. 별표가 붙은 HFD·FLASH는 프로젝트 재학습 구성이고 USDRL에는 프로젝트 학습 NTU60 분류기가 결합돼 있다. 학습 데이터와 입력 변환까지 동일하게 통제한 실험은 아니다.

기존 통합 비교 그림은 보존했다. 원본 RGB는 비식별화된 이미지가 아니므로 공개 게재 전 데이터셋 인물 이미지의 사용 조건과 최종 투고 규격을 확인해야 한다.
