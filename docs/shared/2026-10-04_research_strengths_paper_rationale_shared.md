# 연구의 강점과 논문 작성의 근거

## 1. 연구 전체에 대한 판단

현재 연구는 논문으로 정리할 수 있는 문제 정의, 구현된 방법, 비교 실험 및 결과 검증 근거를 갖추고 있다.
연구의 중심은 **기존 스켈레톤 행동 표현을 유지하면서 낙상 분류 경로를 학습하고,
native skeleton과 외부 RGB 영상에서 그 효과와 제약을 검증한 것**이다.
기존 행동 모델의 어느 부분을 유지하고 어떤 부분을 추가로 학습했는지, 서로 다른 데이터의 감독 정보를
어떻게 사용했는지, 외부 입력에서 성능이 어디까지 유지되고 어디에서 실패하는지를 설명할 수 있다.

이는 실제 수행 기록을 근거로 한 논문 작성 가능성에 대한 판단이다. 특정 학술지·학회의 채택,
최초의 방법이라는 평가 또는 모든 기존 모델에 대한 우위를 보장하는 뜻은 아니다.

논문의 연구 질문은 다음처럼 표현할 수 있다.

> 고정된 스켈레톤 행동 표현을 활용해 기존 ADL 분류 경로를 갱신하지 않으면서 낙상 분기를 학습할 수 있는가?
> 서로 다른 감독 단위로 학습한 이 분기는 학습에 사용하지 않은 외부 영상에서도 낙상과 비낙상을 구분하는가?

## 2. 기존 모델의 기여와 본 연구의 역할

DSTE/USDRL의 행동 표현 학습은 기존 연구의 기여다. [FoundSkel 원논문](https://arxiv.org/abs/2508.12586).
고정 모델 위에 adapter를 학습하는 전이 방식도 선행 연구가 있으므로 adapter라는 개념 자체를 새 기여로
주장하지 않는다. [Houlsby 등의 adapter 연구](https://proceedings.mlr.press/v97/houlsby19a.html),
[AdaptFormer](https://arxiv.org/abs/2205.13535).

본 연구가 설명할 부분은 기존 표현의 낙상 적용 구성, 감독 단위별 학습 절차, 입력 변환과 품질 실패 처리,
원본 기반 기준모델·분류기·외부 모델 비교, 그리고 그 결과로 확인한 적용 범위다.
이러한 사실은 방법론과 실증적 기여의 근거다. 구조적 신규성의 강도는 관련 연구와의 정확한 비교를 통해 평가받아야 한다.

## 3. 강점과 대응하는 근거

### 3.1 기존 ADL 경로를 유지하는 확장 구조

낙상 학습에서는 DSTE와 기존 ADL head를 고정하고 추가된 모듈만 최적화했다.
기존 ADL의 전처리·pooling·분류기를 유지하므로 학습 모듈의 역할이 분명하다.
현재 NTU60 native skeleton의 저장 예측16,487개에서 Top-1 85.285%, Top-5 97.234%를 확인했다.
현재 공동학습 계약에 고정된 인코더·ADL 가중치도 유지되어 있다.

따라서 강점은 **기존 기능을 갱신하지 않는 낙상 확장 설계**다. 과거 기록에는 전체 ADL logits의 전후 동일성 검증도 있으나,
이를 최신 RGB에서 ADL·낙상을 동시에 평가한 결과로 확대하지 않는다. 현재 외부 실행은 J1/G0 낙상 경로이며 ADL 출력을 켜지 않는다.
새 망각 방지 알고리즘을 제안한 연구로 표현할 필요도 없다.

### 3.2 학습 범위가 명확한 전이 구성

2048차원 고정 특징 위에 2048→256→2048 residual adapter와 데이터셋별 head를 학습했다.
Adapter는1,054,976개, 두 head를 포함한 J1 학습 파라미터는1,067,270개다.
인코더 특징을 미리 계산하여 추가 모듈을 학습할 수 있고, J0의 head를 복사한 뒤 up-projection을0으로
초기화하여 J1의 시작 출력을 J0와 일치시켰다.

이는 학습 대상을 제한하고 기존 표현 위에서 변화한 부분을 추적할 수 있다는 장점이다.
전체 RGB 처리에는 검출·pose 추정·3D lifting도 포함되므로 이 숫자만으로 전체 시스템의 경량성,
빠른 추론, 낮은 전력 소비를 주장하지 않는다.

### 3.3 서로 다른 감독 단위를 보존한 학습

SAFER는64프레임 window의 중앙 라벨과4-class head를, FU는 clip을 이루는 window 특징의 평균과
binary head를 사용했다. 두 데이터셋은 residual adapter를 공유하되 집계 방식과 정답 단위를 유지했다.
공통 학습 손실은 두 데이터셋의 가중 cross-entropy 합이다.

이는 프레임 주석에서 만든 window 감독과 영상 clip 감독을 실제로 한 학습 구성에 연결한 방법적 근거다.
FU의 clip 평균은 window 사이의 시간 순서를 모델링하지 않는다. 또한 공유 adapter만의 인과적 이득이나
독립 학습보다 우수하다는 주장은 해당 통제 비교가 확인되지 않은 상태에서 덧붙이지 않는다.

### 3.4 낙상과 의도적 눕기의 혼동을 직접 평가

SAFER 학습에서는 fall·lie_down·lying_down·other를 구분하고, FU 평가에서는 의도적 눕기168개를 비낙상으로 포함했다.
FU의993개 clip을 subject 단위 nested 평가에서 각각 한 번씩 평가했다.

| 평가 범위·단위 | J0 | J1 | 관측된 변화 |
| --- | ---: | ---: | --- |
| FU nested clip 낙상 F1 | 92.771% | 93.333% | +0.562%p |
| FU 의도적 눕기 오탐/168 | 13 | 11 | 오탐2개 감소 |
| SAFER test window 낙상 F1 | 75.359% | 79.709% | +4.349%p |
| SAFER OOD window 낙상 F1 | 46.841% | 52.915% | +6.074%p |

SAFER 값은5fold 모델의 logits 평균 ensemble 결과이며 최종 단일 RGB 모델 결과와 다르다.
이 평가에서는 J1이 precision과 F1을 높이는 대신 fall recall을 일부 낮췄다.
FU의 J1−J0 F1 차이에 대한 사후 피험자 bootstrap 95% 구간은−1.013~+2.189%p로0을 포함한다.
RBF-SVM의 FU F1 93.617%도 J1보다 높다. 따라서 강점은 혼동 문제를 명시하고 비교·검증했다는 점과
관측된 개선이며, 모든 분류기 대비 우위나 통계적으로 확정된 adapter 이득으로 표현하지 않는다.

### 3.5 외부 RGB 영상에서도 확인된 낙상 적응 효과

실제 외부 평가에서는 RGB→사람 검출→2D pose→3D proxy skeleton→DSTE→J1→G0 경로를 사용했다.
원본 기반 기준모델에는 동일한 스켈레톤 입력과 고정 DSTE에 NTU60 선형 분류기를 연결했다.
기준모델은 J1/G0 없이 A43를 낙상으로 읽는 구성이며 저자 배포 완성형 낙상 분류기는 아니다.

| 데이터셋·단위 | 원본 기준 P/R/F1 | 사용자 P/R/F1 | F1 차이 |
| --- | --- | --- | ---: |
| Le2i130 영상 | 98.63 / 72.73 / 83.72% | 95.56 / 86.87 / 91.01% | +7.28%p |
| CAUCA100 영상 | 90.91 / 40.00 / 55.56% | 97.50 / 78.00 / 86.67% | +31.11%p |

P/R/F1은 각각 낙상 양성 클래스의 Precision·Recall·F1이며 모든 수치는%다.
모든 평가 영상과 처리 실패를 분모에 포함했고 타깃 데이터로 추가 학습·임계값 조정을 하지 않았다.
현재 확인된 학습 기록에서 두 데이터셋은 낙상 학습에 사용하지 않았다. 이전 진단에서 관찰한 자료이므로
완전히 처음 공개한 blind test라고 부르지 않는다. 모든 기반 모델의 사전학습 이미지 중복을 배제한 것도 아니다.

선정한 HFD·Privacy X3D-UDA RGB·FLASH와의 동일 영상 비교에서도 사용자 모델의 F1이 두 데이터셋 모두 가장 높았다.
HFD는 저자 C3D+직접 학습한 SVM, FLASH는 공식 모델을 UP-Fall로 학습한 재현본이며,
X3D는 저자 공개 RGB+depth UDA 가중치의 RGB 평가다. 원논문의 서로 다른 평가 수치를 비교한 표가 아니다.

CAUCA에서는 사용자 모델이 낙상50개 중39개를 검출하고 비낙상50개 중1개에 경보를 냈다.
비낙상 영상의 오탐률은2%지만 낙상 미탐은11개 남는다. 낮은 비낙상 경보와 검출률의 균형이 장점이며,
실환경의 시간당 경보율·안전성·실시간 응답 성능이 검증됐다는 뜻은 아니다.

### 3.6 수치의 근거와 실패 원인을 추적할 수 있는 실험 체계

FU의 subject 분리·nested 선택·전체 OOF 예측을 검산했고, 저장된 특징에서 checkpoint 출력을 다시 계산했다.
외부 평가에서는 동일 시험 영상·정답, 처리 실패 포함 여부, 영상/사건 지표 구분과 혼동행렬을 확인했다.
선택적 성공 사례만으로 평가하지 않고 입력 품질 거부·짧은 입력·분류 미탐을 구분했다.

이러한 검증은 성능 수치와 실행 산출물이 대응한다는 근거다. 모든 데이터 누출 가능성이나 입력의 모든 의미적 오류를
배제했다는 증명은 아니다. 전처리의 좌표/confidence 대응 불일치 등 확인된 제한은 그대로 보고해야 한다.
재현성을 위한 기록은 연구의 신뢰도를 뒷받침하지만 그것만으로 방법의 신규성을 대신하지는 않는다.

## 4. 확장 실험이 제공하는 연구적 해석

| 확장 | 확인된 사실 | 논문에서의 의미 |
| --- | --- | --- |
| V3 연속 입력 구성 | 유효2D 근거를 사용한 사후 R3 검사에서 경계 이상 비율97.155% 감소 | 입력의 연속성 진단; 의미적3D 정확도·낙상 성능 개선율과 구분 |

현재 외부 경로에는 G1/G2·ADL 출력·상태·회복 모듈을 사용하지 않는다.

## 5. 논문으로 쓸 수 있는 이유와 주장 범위

현재 자료에는 다음 연결이 존재한다.

1. **문제:** 범용 행동 표현을 낙상에 적응시키되 기존 ADL 경로를 갱신하지 않고, 의도적 눕기와 외부 입력의 어려움을 다룬다.
2. **방법:** 동결 인코더·공유 residual adapter·감독 단위별 집계와 head·단계적 학습·RGB 연결 절차가 구체적으로 정의되어 있다.
3. **검증:** native ADL 확인, FU subject nested 평가, SAFER J0/J1 비교, 원본 기준 및 선정 모델의 외부 평가가 있다.
4. **관찰:** 원본 기준 대비 외부 F1 개선, 낮은 CAUCA 비낙상 오탐, 데이터별 성능 차이와 실패 원인을 확인했다.
5. **해석:** 추가 모듈의 실제 이득과 미채택 이유, 통계적 불확실성, 입력·과제 차이를 구분할 수 있다.

따라서 **수행한 방법과 비교·분석을 중심으로 원고를 구성할 실증적 근거는 확보되어 있다**는 판단이 가능하다.
논문의 초점은 동결 스켈레톤 표현의 낙상 적응과 외부 평가에 두는 것이 현재 자료와 맞는다.
특정 활성화 함수·optimizer의 최적성을 주장하지 않는다면 모든 조합 비교가 원고 작성의 선행 조건은 아니다.

전체 도메인에서 안정적이라고 표현할 근거는 부족하다. URFD 영상 F1은58.82%, OOPS 사건 F1은55.54%였고,
과거 추가 비교의 SAFER 학습 ST-GCN++·MS-G3D에는 사용자 모델보다 높은 성능도 있었다.
따라서 메인 세 모델에 대한 관측 우위를 전체 SOTA로 확대하지 않는다.
RGB 기반 ADL·낙상 동시 인식, 낙상 후 회복 탐지, 실시간 인과성, 임상·운영 안전성도 현재 결과의 주장이 아니다.

## 6. 논문 기여 서술 초안

> 본 연구에서는 사전학습된 스켈레톤 행동 표현을 이용하여 기존 ADL 분류 경로를 갱신하지 않는 낙상 적응 구성을 구현하였다.
> 고정 인코더의 특징에 공유 residual adapter와 데이터셋별 분류기를 적용하고, SAFER의 window 감독과 FU-Kinect-Fall의
> clip 감독을 각각의 집계 방식으로 학습에 반영하였다. 이러한 구성은 학습 범위를 추가 모듈로 제한하면서 서로 다른
> 정답 단위의 낙상 자료를 활용하는 절차를 제공한다.
>
> 실험에서는 native skeleton의 피험자 분리 평가와 외부 RGB 영상 평가를 구분하여 수행하였다. FU의 nested 평가와
> SAFER의 J0/J1 비교에서 낙상 분류 및 의도적 눕기 오탐을 분석하고, 외부 영상에서는 고정 DSTE의 NTU60 분류기와
> 낙상 적응 경로를 동일한 입력·정답으로 비교하였다. 사용자 모델은 Le2i와 CAUCAFall에서 각각91.01%,86.67%의
> 영상 F1을 기록하여 원본 기반 기준모델보다7.28%p,31.11%p 높았다. 특히 CAUCAFall에서는 비낙상50개 중1개에
> 경보를 내면서 낙상50개 중39개를 검출하였다.
>
> 또한 선정한 세 외부 비교 모델의 실제 실행 결과와 비교하고, 처리 실패를 포함한 전체 분모 및 영상·사건 평가 단위를
> 명시하였다. 이 결과는 고정된 행동 표현을 낙상에 적응시키는 구성의 적용 가능성과 두 외부 데이터셋에서의 효과를
> 뒷받침한다. 동시에 FU의 작은 adapter 이득에 대한 불확실성, 외부 도메인별 성능 저하, 입력 전처리의 제약과
> 상태 안정화의 상충 관계를 함께 제시하여 적용 범위를 구체화하였다.
