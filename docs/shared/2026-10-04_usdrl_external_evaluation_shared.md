# USDRL의 Le2i와 CAUCA 낙상 평가 결과

- 문서 ID: `DOC-20261004-usdrl-external-evaluation-R2`
- 기준일: 2026-10-04
- 연구 상태: `completed`

공식 DSTE와 프로젝트에서 NTU60으로 재학습한 선형 분류기를 연결한 결과, 두 데이터셋에서
**낙상 클래스 A43가 실제로 출력되었다.** 사건 단위 F1은 Le2i 81.82%, CAUCA 54.05%다.
J1·G0는 사용하지 않았으며 추가 학습과 평가 데이터에 맞춘 임계값 조정도 하지 않았다.

## 평가 가능성과 모델의 구분

USDRL은 스켈레톤 행동 표현을 학습하는 방법이며, 확보된 공식 사전학습 DSTE에는 행동 분류기가
포함되지 않는다. 따라서 이 파일만으로 낙상 여부를 직접 판정할 수는 없다. 공식 downstream
절차처럼 고정된 특징 추출기에 분류기를 연결해야 한다.
[USDRL 공식 구현](https://github.com/wengwanjiang/USDRL),
[행동 인식 코드](https://github.com/wengwanjiang/USDRL/blob/main/action_recognition.py).

프로젝트에는 공식 NTU60 linear evaluation 절차를 따라 학습한 60종 행동 분류기가 있다.
이를 연결하고 A43인 falling down을 낙상으로 읽으면, J1과 G0 없이 외부 낙상 평가가 가능하다.
다만 이 구성은 **USDRL 기반 NTU60 기준선**이며, 저자가 학습해서 배포한 낙상 전용 모델과는
구분해야 한다. [NTU 공식 클래스 정의](https://rose1.ntu.edu.sg/dataset/actionRecognition/).

## 비교할 입력과 판정

기존 J1/G0 평가와 같은 Le2i 130개 및 CAUCA 100개를 대상으로 한다. 스켈레톤 품질 검사를
통과한 영상은 각각 119개와 93개이며, 나머지도 평가 분모에 남겨 경보 없음으로 처리했다.
추가 학습이나 평가 데이터에 맞춘 임계값 조정은 하지 않았다.

비교할 구성은 다음과 같다.

- 기준선: 기존 RGB 기반 스켈레톤 입력 → 공식 DSTE → NTU60 선형 분류기.
- 현재 모델: 같은 스켈레톤 입력 → 공식 DSTE → J1 → G0.

25 Hz 시간축에서 64프레임 창을 8프레임씩 이동한다. 기준선의 60종 예측 중 A43가 최상위일 때만
낙상으로 판정하고, 연속된 낙상 판정의 시작을 경보로 사용한다. 경보와 실제 낙상은 기존과 동일하게
낙상 시작 전 0.5초부터 끝 후 3초까지 일대일로 연결한다. 사건 단위 F1과 영상 단위 분류 지표를
구분해 보고한다.

## 낙상 클래스 출력과 검출 성능

품질 통과 영상의 6,286개 구간을 특징 추출기부터 새로 추론하고 전체 결과를 독립 검산했다.

| 평가 항목 | Le2i | CAUCA |
| --- | ---: | ---: |
| 전체 평가 영상 | 130 | 100 |
| A43로 분류된 구간 / 전체 추론 구간 | 243 / 4,082 | 59 / 2,204 |
| 한 번 이상 A43를 예측한 영상 | 73 | 22 |
| 실제 낙상 검출 / 정답 낙상 사건 | 72 / 99 | 20 / 50 |
| 사건 TP / FP / FN | 72 / 5 / 27 | 20 / 4 / 30 |
| 사건 precision | 93.51% | 83.33% |
| 사건 recall | 72.73% | 40.00% |
| 사건 F1 | **81.82%** | **54.05%** |
| 영상 단위 F1 | 83.72% | 55.56% |
| 영상 단위 accuracy | 78.46% | 68.00% |

구간들은 서로 겹치므로 A43 구간 수를 독립된 낙상 횟수로 해석하면 안 된다. 또한 영상에서
한 번이라도 A43가 나왔다는 사실과 정답 낙상의 허용 시간 안에 경보가 발생했다는 사실은 다르다.
낙상 영상의 중복·추가 경보도 사건 FP로 세므로 사건 지표와 영상 지표를 구분했다.

## 현재 J1과 G0 모델과의 비교

| 모델 | Le2i 사건 F1 | CAUCA 사건 F1 |
| --- | ---: | ---: |
| USDRL 기반 NTU60 기준선 | 81.82% | 54.05% |
| 현재 DSTE + J1 + G0 | 91.01% | 82.98% |
| 현재 모델의 차이 | +9.19%p | +28.92%p |

NTU60 기준선도 낙상을 검출하지만 현재 J1/G0보다 미탐이 많다. Le2i 미탐 27건은 입력 품질
거부 11건과 입력 품질을 통과했으나 A43를 예측하지 않은 16개 낙상 영상으로 나뉜다.
CAUCA 미탐 30건은 같은 순서로 5건과 25건이다. 이 분해는 결과를 설명하기 위한 분석이며,
분석 후 판정 기준을 바꾸거나 재학습하지 않았다.

## 실제 출력 사례와 검증

| 데이터와 사례 | 정답 낙상 구간 | A43 경보 시각 | A43 예측 구간 수 |
| --- | --- | --- | ---: |
| Le2i Coffee room 01 video 1 | 1.92–3.20초 | 2.84초 | 5 |
| CAUCA FallBackwardsS1 | 약 1.93–3.77초 | 3.48초 | 2 |

새로 추론한 DSTE 특징은 기존 J1/G0 평가에서 adapter에 넣기 전의 특징과 모든 구간에서
정확히 일치했다. 별도 선형 계산에서도 전체 6,286개 구간의 최상위 클래스가 일치했고,
경보 시각·클래스 빈도·사건 및 영상 지표의 독립 검산을 통과했다. 평가 중 가중치는 바뀌지 않았다.
전체 사례와 비교 지표는 [사례별 결과](2026-10-04_usdrl_external_cases.csv)와
[성능 비교표](2026-10-04_usdrl_external_results.csv)에 제공한다.

## 해석의 한계

이 비교는 USDRL 논문의 원래 평가를 그대로 재현하는 실험이 아니다. NTU의 Kinect 실측
스켈레톤과 달리 RGB에서 추정한 3차원 스켈레톤을 사용하며, 전체 행동 clip 대신 연속 영상의 창을
분류한다. 또한 J1/G0는 낙상 관련 데이터로 학습되었으므로 두 결과의 차이를 adapter 구조만의
효과로 해석할 수 없다. 입력 추정 오차, 도메인 차이와 학습 데이터 차이가 함께 반영된다.
